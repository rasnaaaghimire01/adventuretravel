**Adventure Travel Website**

**1.Project Overview**
The Adventure Travel Website is a static website developed using HTML, CSS, and basic JavaScript.
This project provides information about adventure travel services, destinations, and allows users to contact and ask queries.
The website is created as an academic project to practice front-end web development skills and proper website structure.

**2.Objectives**
To design a simple and attractive adventure travel website
To practice HTML and CSS for web design
To create multiple linked web pages
To understand website folder and file structure

**3.Technologies Used**
HTML5 – For website structure
CSS3 – For styling and layout
JavaScript – For basic interactivity

**4.Project Files & Structure**
adventuretravel/
│
├── index.html        (Home Page)
├── services.html     (Services Page)
├── contact.html      (Contact Page)
├── ask.html          (User Query Page)
│
├── css.zip           (CSS files)
├── images.zip        (Website images)
│
└── README.md

**5.Website Pages**
Home (index.html) – Main landing page of the website
Services (services.html) – Adventure travel services information
Contact (contact.html) – Contact details and form
Ask (ask.html) – Page for user questions and queries

**6.How to Run the Project**
Download or clone this repository
Extract css.zip and images.zip into the project folder
Open the project folder
Double-click on index.html
The website will open in your web browser
No installation or server setup is required.
